# Percent

A responsive React storefront foundation for Percent, a limited-edition apparel brand.

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run build
npm run lint
```

## Project structure

- `src/data` contains typed, API-ready homepage mock data and centralized temporary image references.
- `src/types` defines the product, hero, navigation, category, campaign, and content models.
- `src/components` contains reusable layout, product, common, and homepage section components.
- `src/pages` contains the homepage plus safe placeholder routes for future development.

The project intentionally has no backend, authentication, checkout, or admin interface in this phase.
